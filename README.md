A program-drawn newspaper infographic summing up the world's news of Wednesday 18 November 2026: the U.S. strike on Iran's Qeshm Island and Iran's drone retaliation, the Kerch Bridge hit, the Shenzhen summits, Ebola in Congo, the U.S. losing measles-free status, the Papua New Guinea quake, and the day's markets.

## Run it

```sh
python3 render.py
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`render.py` draws `entry.png` (1024×1024, Pillow) from the day's reported facts; `main.py` (standard library only) copies it to the output directory.
